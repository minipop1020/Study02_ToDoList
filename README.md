# Study02_ToDoList

브라우저에서 HTML 파일 하나로 실행되는 개인용 할 일 관리 앱입니다.
하루 10~20개의 할 일을 업무·개인·공부로 나누어 관리하고, 진행률을 한눈에 확인할 수 있습니다.

> **현재 상태:** 구현 완료 — [PRD.md](PRD.md)의 요구사항에 따라 `index.html` 하나로 구현했습니다.

## 주요 기능

- 할 일 추가, 수정, 삭제
- 완료 체크
- 카테고리 분류: 업무 / 개인 / 공부
- 전체 및 카테고리별 진행률 보기
- 브라우저 저장소(localStorage)에 저장해 새로고침해도 데이터 유지

## 기술 스택

- HTML, CSS, 순수 자바스크립트 (외부 라이브러리 없음)
- `index.html` 파일 하나로 구성, 서버나 설치 불필요

## 실행 방법

`index.html` 파일을 크롬 또는 엣지 브라우저로 열면 바로 실행됩니다.
